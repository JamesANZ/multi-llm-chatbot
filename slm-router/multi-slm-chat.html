How to Use
  1. Click Settings to configure your Hugging Face API token
  2. Add SLM models or use the default collection
  3. Each model should have a domain/category (e.g., "general", "coding", "australian_tax")
  4. Type your prompt and press Send
  5. The router will automatically classify your prompt and route it to the best SLM

Tips: Add niche models for specialized domains (e.g., Australian tax questions → model with "australian_tax" domain)
